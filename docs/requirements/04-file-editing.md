# F004 修改文件

- 状态：待开发。
- 优先顺序：阶段 4。
- 依赖：F003 项目文件读取和搜索。

## 用户场景

用户提出明确修改要求，助手读取相关文件，生成差异预览，用户确认后应用修改，并说明变更内容。

## 功能范围

- 在项目范围内创建或修改文本文件；复用文件访问边界和敏感文件排除规则。
- 提供修改前后的差异预览和确认步骤；取消时不写入。
- 应用前检查文件是否在预览后被外部修改，有冲突时停止并重新读取。
- 保留用户已有修改，不覆盖与需求无关的内容。
- 提供本次修改的恢复方式，恢复时同样检查后续变更，避免覆盖新内容。
- 本阶段不包含批量删除、自动 Git 提交或推送，也不执行生成的代码。

## 验收标准

- [ ] 能为一个小型代码修改生成准确差异，预览时文件未被写入。
- [ ] 确认后应用差异，取消后文件保持不变。
- [ ] 外部修改导致冲突时不会静默覆盖。
- [ ] 无关用户修改、文件编码和换行方式得到保留。
- [ ] 不能写入项目外部或受保护文件。
- [ ] 能恢复本次修改；存在后续冲突时明确说明并停止恢复。
