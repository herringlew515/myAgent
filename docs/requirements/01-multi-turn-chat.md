# F001 多轮对话

- 状态：已实现，离线验证通过；真实模型多轮验收待完成。
- 优先顺序：阶段 1。
- 实现位置：`test.py` 的 `run_chat()` 和 `main()`。

## 用户场景

用户先问“23 乘以 47”，再问“结果再乘以 2”，助手能够根据上一轮的结果继续回答。

## 功能范围

- 无命令行参数时进入持续输入循环；传入问题时仍单次回答后退出。
- 保存当前进程内的用户消息、模型回复和工具结果，每轮一起交给 Agent。
- 支持 `exit`、`quit`、`Ctrl+C` 和输入结束退出，支持 `/clear` 清空历史。
- 忽略空白输入；请求失败时不追加失败轮次，保留此前成功历史并允许继续输入。
- 本阶段不包含历史落盘、跨进程恢复或自动压缩上下文。

## 验收标准

- [x] 离线测试确认下一轮收到完整历史，包含工具调用和结果。
- [x] `/clear` 后的新请求不携带旧历史。
- [x] 空白输入和退出命令不会调用模型；输入结束和中断可以退出。
- [x] 某一轮失败后可以继续对话，且不会输出原始服务端异常正文。
- [x] 无参数进入多轮模式；传入问题仍只执行一次。
- [ ] 使用当前可用模型，先计算 `23 × 47`，再追问“结果再乘以 2”，确认分别回答 `1081` 和 `2162`。
