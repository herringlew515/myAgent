# F006 · AI 群聊原型

## 场景与范围

两个浏览器标签页使用不同昵称加入同名群，实时聊天；任一成员输入 `@AI` 时，AI 结合该群已有讨论回答，全群可见。

- 将 Agent 和工具从命令行入口抽取到 `agent.py`，保留命令行功能。
- FastAPI + WebSocket 实现实时通信，SQLite 保存身份、群成员和消息。
- 昵称身份由服务端创建，随机令牌认证；数据库仅保存令牌哈希。
- 同名群公开加入；HTTP 历史和 WebSocket 均校验成员身份。
- 最近 100 条历史展示，最近 40 条消息作为 AI 上下文，包含成员 ID 和昵称。
- 上下文截断到触发消息 ID，同群 AI 请求按 FIFO 顺序执行。
- 模型失败以群内系统消息反馈，不中断聊天；避免暴露服务商错误正文。
- 网页支持断线重连、标签页身份恢复、移动端布局和安全纯文本渲染。

## 验收

自动测试位于 `tests/test_group_chat.py`：

- 双用户广播、发送者防伪造、重新连接恢复历史、重新打开数据库后记录保留。
- AI 回复广播、多人身份上下文、群之间隔离、AI 请求按序处理。
- AI 失败后后续 AI 请求和普通聊天正常。
- HTTP 与 WebSocket 身份和成员校验、WebSocket 跨站来源校验。
- 空消息、超长消息、错误 JSON 被拒绝，连接继续可用。
- 网页和脚本可访问，昵称及群名校验。

以上测试使用假模型；真实模型和视觉验收结果应与离线测试分开记录。

### 2026-09-16 验证结果

- `python -m unittest discover -s tests -v`：12 项通过，含原有 6 项命令行测试。
- `node --check static/app.js`、Python 编译检查、`pip check`：通过。
- 启动实际 Uvicorn 服务后运行 `python scripts/smoke_chat.py --live-ai`：通过。两位独立用户交换消息；AI 读取第一位用户提供的 23 和 47，回答第二位用户的追问，返回 1081；两端收到相同回复；HTTP 历史包含完整对话。
- 网页 HTTP 访问通过；浏览器工具无可用浏览器，因此尚未完成视觉与真实浏览器交互验收。

## 第一版限制

本机单进程运行。没有正式账号、私密群、消息分页、分布式广播、消息投递确认或持久任务队列。服务重启会丢失待执行 AI 任务，但保留已存储消息。连接瞬断时刚发送的消息可能未送达，重新连接后以服务端历史为准。上线前需补充账号体系、访问控制、限流和部署方案。
