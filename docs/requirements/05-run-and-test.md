# F005 运行程序和测试

- 状态：待开发。
- 优先顺序：阶段 5。
- 依赖：F004 修改文件。

## 用户场景

助手修改代码后运行指定测试，读取失败信息并尝试修正，最后报告测试是否通过及剩余问题。

## 功能范围

- 展示即将执行的命令和工作目录，在用户授权范围内运行。
- 捕获标准输出、错误输出、退出码和耗时，限制执行时间及输出大小。
- 使用项目虚拟环境执行 Python 和测试；正确处理含空格的参数。
- 支持中止运行，超时后停止相关子进程并报告原因。
- 修复循环设置明确次数上限，每次依据实际错误调整，达到上限后汇报未解决问题。
- 执行代码可能修改文件或访问网络，实施前需确定运行隔离方式与命令授权范围；不能仅依靠工作目录提供隔离。
- 不自动安装依赖、部署、推送 Git 或执行删除类操作；这些需要单独定义范围。

## 验收标准

- [ ] 成功测试返回真实的成功退出码和输出摘要。
- [ ] 测试失败时显示实际失败信息，不报告为通过。
- [ ] 命令不存在、超时和用户取消均有明确反馈，并停止相关执行。
- [ ] 输出过大时限制长度并提示截断；凭据不写入展示日志。
- [ ] 在可控样例中完成“测试失败 → 修改 → 再测通过”，展示修改与验证结果。
- [ ] 重复失败达到次数上限后停止，不无限运行。
- [ ] 未获得授权的命令不执行；运行隔离方案及其限制有明确记录。
