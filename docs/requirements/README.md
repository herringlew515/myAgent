## 如何维护

1. 新功能先复制 [需求模板](TEMPLATE.md)，使用连续编号，例如 `06-session-storage.md`，并加入上表。
2. 开发前写清用户场景、包含与不包含的范围、验收标准和依赖。
3. 开发时更新状态；完成后记录实现位置、验证结果和剩余问题。
4. 验收勾选必须有实际检查依据，区分离线测试与真实模型验证。
5. 状态使用：待讨论、待开发、开发中、待验收、已完成、暂缓。若实现完成但验收未全部完成，写明具体差距。

## 当前技术基础

- `agent.py`：共用 Agent 创建、乘法与时间工具；`test.py`：命令行单次及多轮对话。
- `server.py` / `storage.py` / `static/`：群聊后端、持久化、网页。
- `tests/test_chat.py`：对话历史、退出、异常恢复和单次模式的离线测试。
- LangChain 负责 Agent 工具调用循环，模型服务通过环境变量配置。
- 后续按代码复杂度拆分命令行、Agent、工具和配置模块；模块拆分服务于功能开发，不要求先更换框架。
