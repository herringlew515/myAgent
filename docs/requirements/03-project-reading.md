# F003 项目文件读取和搜索

- 状态：待开发。
- 优先顺序：阶段 3。
- 依赖：F002 工具调用过程展示。

## 用户场景

用户问“这个项目怎么运行”，助手读取 README 和相关入口；用户问“`multiply` 在哪里被引用”，助手搜索代码并给出文件位置。

## 功能范围

- 列出项目目录、按范围读取文本文件、按关键词搜索文件内容。
- 以指定项目根目录为访问范围，解析实际路径后阻止越界访问，包括符号链接或目录联接导致的越界。
- 默认跳过 `.git`、`.venv`、缓存以及 `.env` 等凭据文件；配置示例 `.env.example` 可读。
- 返回相对路径和行号，限制单文件读取量和搜索结果数量，提供继续读取的方式。
- 依据实际读取内容回答；不能确认时说明依据不足。
- 本阶段不修改文件，不运行终端命令；关键词搜索不承诺完整语义调用分析。

## 验收标准

- [ ] 能根据项目 README 和入口代码说明运行命令，并引用对应文件位置。
- [ ] 能找到 `multiply` 的定义和相关文本引用。
- [ ] 文件不存在、编码不支持或无匹配时，返回明确结果。
- [ ] 大文件与大量匹配被限制，并说明内容是否截断。
- [ ] 根目录之外的路径和指向外部的链接均不能读取。
- [ ] 默认排除的环境、缓存和凭据文件不会进入模型上下文。
- [ ] 读取与搜索过程可通过工具详情观察，项目文件保持不变。
