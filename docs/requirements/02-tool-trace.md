# F002 工具调用过程展示

- 状态：待开发（下一步）。
- 优先顺序：阶段 2。
- 依赖：F001 多轮对话。

## 用户场景

用户希望知道助手是否真的调用了乘法或时间工具，并在出错时区分工具执行失败和模型请求失败。

```text
你：计算 23 乘以 47
[工具] multiply(a=23, b=47)
[结果] 1081
助手：结果是 1081。
```

## 功能范围

- 展示实际工具执行的开始、工具名、参数、结果或错误。
- 区分同轮多次工具调用，将每个结果关联到对应调用。
- 单次与多轮模式均支持；建议提供 `--verbose` 开关启用详情。
- 输出过长时截断并提示；敏感字段脱敏。
- 仅展示工具执行事件，不将模型内部推理作为工具日志输出。

## 验收标准

- [ ] 乘法请求显示正确的工具名、参数和实际结果。
- [ ] 不调用工具的问候不显示工具事件。
- [ ] 同轮调用多个工具时，结果与调用一一对应。
- [ ] 多轮追问不会重复输出上一轮工具事件。
- [ ] 工具失败时显示失败状态，不伪造成功结果，程序按既定异常流程处理。
- [ ] 大量输出有截断提示，敏感字段不会显示。
- [ ] 关闭详情后仍可正常获得最终回答。
