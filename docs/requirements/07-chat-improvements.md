## 数据兼容

原 SQLite 数据库启动时新增 images 表和 messages.image_id 可空列，不删除或重建已有消息。身份、群成员和历史保留。图片内容存入数据库，备份 chat.db 即可包含图片；运行时应使用 SQLite backup API 生成一致备份。

客户端优先恢复当前标签页身份，新标签页或重开浏览器回退到本机最近身份。更换身份会清除本地身份记忆，既有其他标签页仍保留各自会话。网站域名改变时浏览器存储不共享。
